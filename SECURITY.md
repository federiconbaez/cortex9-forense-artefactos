# Security

Este proyecto contiene **únicamente modelos formales** de mecanismos de
forense móvil (contadores, RPMB, Gatekeeper, etc.) y una herramienta de
**transcripción atestada** (PATE-FNBR).

## Alcance

- No incluye exploits, bypass de PIN/RPMB, ni recetas contra dispositivos.
- PATE registra lo **declarado** por el operador; no ejecuta extracciones.

## Reportes

Abrir un issue privado o contactar al maintainer del repo. No enviar
PoCs ofensivos contra hardware de terceros.
